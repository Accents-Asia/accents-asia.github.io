## Accent Asia 

Jekyll based site for Accent Asia

### Installation

1. Install Ruby
  * $ sudo apt install ruby ruby-dev
2. Clone the repository
3. Run `bundle install` in the repository directory
4. Run `bundle exec jekyll serve` in the repository directory
5. Open `http://localhost:4000` in your browser

#### Generate Tag Files

Run the ```_posts_tags/_gen_posts_tags_files.sh``` script to generate the tag files for the posts.
